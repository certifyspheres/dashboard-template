## 🔍 Quick Reference

### Installation
```bash
npm install
npm run dev
```

### Login
```
admin@admin.com / admin123
```

### Theme Controls
- **Color:** Click palette icon (🎨) in header
- **Mode:** Click sun/moon icon in header

### Build
```bash
npm run build
```

### Key Files
- `src/App.jsx` - Main app
- `src/components/Layout.jsx` - Common layout
- `src/context/ThemeContext.jsx` - Theme management
- `src/index.css` - Theme styles
