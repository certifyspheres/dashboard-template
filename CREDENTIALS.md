## Features to Test

### Theme Customization
- Click the **palette icon** (🎨) in the header to change color themes
- Click the **sun/moon icon** to toggle between light and dark mode

### Navigation
- Use the sidebar to navigate between pages
- Dashboard - View statistics and charts
- Tables - Manage users with search and filters
- Charts - View different chart types
- Profile - Edit user profile

### Color Themes Available
1. Blue (default)
2. Green
3. Purple
4. Orange
5. Pink

All themes work in both light and dark modes!
