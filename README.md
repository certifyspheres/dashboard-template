# AdminPro - Professional Admin Dashboard Template

A modern, feature-rich admin dashboard template built with React, Vite, and Tailwind CSS. Perfect for selling on Envato and other marketplaces.

## Features

✨ **Complete Dashboard Solution**
- Beautiful landing page with pricing sections
- Login and registration pages
- Comprehensive dashboard with statistics
- Advanced data tables with search and filters
- Multiple chart types (Line, Bar, Area, Pie, Radar)
- User profile management

🎨 **Customization Options**
- 5 color themes (Blue, Green, Purple, Orange, Pink)
- Light and dark mode support
- Fully responsive design
- Professional UI components

📊 **Data Visualization**
- Recharts integration for beautiful charts
- Real-time data updates
- Interactive tooltips and legends

🔐 **Authentication**
- Login page with social auth options
- Registration page
- Protected routes
- Session management

## Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first CSS framework
- **React Router** - Client-side routing
- **Recharts** - Composable charting library
- **Lucide React** - Beautiful icon library

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open browser and go to `http://localhost:5173`

4. Click "Login" and use demo credentials:
   - **Email:** admin@admin.com
   - **Password:** admin123

5. Build for production:
```bash
npm run build
```

6. Preview production build:
```bash
npm run preview
```

## 🎨 Theme System

### Available Themes
- **Blue** - Professional & Corporate (Default)
- **Green** - Eco-friendly & Health
- **Purple** - Creative & Modern
- **Orange** - Energetic & Warm
- **Pink** - Playful & Vibrant

### How to Change Themes
1. **Color Theme:** Click the palette icon (🎨) in the header
2. **Dark/Light Mode:** Click the sun/moon icon (☀️/🌙)
3. Preferences are saved automatically!

### Theme Features
- ✅ 5 color options
- ✅ Dark/Light mode
- ✅ Persistent storage
- ✅ Smooth transitions
- ✅ Works on all pages
