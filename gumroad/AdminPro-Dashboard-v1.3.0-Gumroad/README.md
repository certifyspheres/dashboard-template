## 🚀 **Quick Start (5 Minutes)**

1. **Navigate to source code:**
   ```bash
   cd source-code
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   http://localhost:5173

5. **Login with demo account:**
   - Email: admin@admin.com
   - Password: admin123

**That's it! You're now running AdminPro! 🎉**
