## 🚀 How to Use

### Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to http://localhost:5173
# Click "Login" and use: admin@admin.com / admin123

# Test theme features:
# - Click palette icon (🎨) to change colors
# - Click sun/moon icon to toggle dark/light mode
```

### Build for Production
```bash
npm run build
# Output in dist/ folder
```

## 🎨 Theme Implementation Details

### Color Theme System
**File:** `src/index.css`
```css
[data-theme="blue"] { --color-primary: 59 130 246; }
[data-theme="green"] { --color-primary: 34 197 94; }
[data-theme="purple"] { --color-primary: 139 92 246; }
[data-theme="orange"] { --color-primary: 249 115 22; }
[data-theme="pink"] { --color-primary: 236 72 153; }
```

### Theme Picker UI
**File:** `src/components/Header.jsx`
- Dropdown with 5 color options
- Each option shows color circle + label
- Active theme has checkmark
- Click outside to close
- Saves to localStorage

### Dark/Light Mode
**File:** `src/context/ThemeContext.jsx`
- Toggle between light/dark
- Adds/removes 'dark' class on html
- Saves preference to localStorage
- Loads on app start
